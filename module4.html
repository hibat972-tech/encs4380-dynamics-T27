Module 4 of 4: work backwards from a curve

Guess the sensor

The page has picked a sensor at random and hidden its parameters. You only see its noisy response, just as you would with a real sensor on a bench. Read the curve, estimate the parameters, then reveal the truth.

Methods you can use (from Modules 1–3)

First order, step input

\(K = y_\infty / A\): read the flat end of the curve and divide by the step size.

\(\tau\) is the time at which the curve reaches \(0.632\,y_\infty\).

Log method: \(\ln E_m = \ln\!\big(1-y/y_\infty\big) = -t/\tau\). Fit a straight line; its slope is \(-1/\tau\).

First order, sine input

Measure the time \(\Delta t\) between an input peak and the next output peak: \(|\phi| = \omega\,\Delta t\).

\[ \tau = \frac{\tan|\phi|}{\omega},\qquad K=\frac{Y}{A}\sqrt{1+(\omega\tau)^2} \]

where \(Y\) is the output amplitude.

Second order, step input

Read the overshoot \(M_p\) (as a fraction) and the peak time \(t_p\):

\[ \zeta=\frac{-\ln M_p}{\sqrt{\pi^2+\ln^2 M_p}} \] \[ \omega_n=\frac{\pi}{t_p\sqrt{1-\zeta^2}} \]

Scoring

Each parameter scores 100 points if it is within 10% of the true value. Beyond that the score falls in a straight line to 0 points at 50% error. Your round score is the average over the parameters you estimate.
