Section 3.2 of the assignment

Validation checks

Modules 1–3 must reproduce six results from the lecture slides. Each check below is computed in your browser when the page loads, by the same functions that draw the module plots, and then compared with the expected value.

How a check passes

  • Expected is the number printed in the assignment. Calculated is what the toolkit's code produces.
  • Tolerance is half a unit in the last digit the assignment prints. For example, 0.632 allows ±0.0005, 21.8° allows ±0.05° and 0.52 ms allows ±0.005 ms. A check passes only if every row is within its tolerance.
  • Method says where the number comes from. curve: read off a sampled response, the way you would read a plot. formula: the closed-form expression. eig(A): eigenvalues from the state matrix.
  • No result is typed in by hand. Change a formula in js/dyn-math.js and the affected checks turn to Fail.
