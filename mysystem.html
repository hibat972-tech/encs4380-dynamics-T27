My System: the Micromouse drive motor

The drive motor is the first-order plant: PWM duty (in %) goes in, wheel speed from the encoder comes out. This page takes K and τ (measured, or typed in), designs a PI speed controller for a damping ratio between 0.6 and 0.8, checks that the PWM command stays between 0 and 100%, and produces the Arduino code.

Plant model

Step test: apply a PWM step of size ΔU from rest and log the encoder speed. Then

  • K = Δy / ΔU: the change in final speed divided by the PWM step.
  • τ = the time for the speed to reach 63.2% of its total change (also estimated from the slope −1/τ of ln(1 − y/yfinal)).

Both formulas are the Homework 1, Module 1 results. The tool below applies them to your logged data.

How to log the step test (what we still need to measure)
  1. Put the robot on a stand so the wheels spin freely, or run it on a long clear straight. Use a fully charged battery and note its voltage.
  2. With the motor at rest, command a constant PWM step (for example 50%) and log the encoder speed every 2 to 10 ms for about 10 time constants (about 1 s).
  3. Convert encoder counts per sample to your speed unit (for example mm/s) and paste “time, speed” here.
  4. Repeat at two or three different PWM levels. If K changes a lot between levels the motor is not linear there (dead zone or saturation). Use the level around your cruising speed.
  5. Keep the log file. Your report should cite it.
// Step-test logger (adapt the three constants to your hardware)
const int MOTOR_PWM_PIN = 9;          // your motor driver PWM pin
const float PWM_STEP_PERCENT = 50.0f; // size of the step
const unsigned long LOG_US = 5000UL;  // log every 5 ms
volatile long encoderCount = 0;       // increment this in your encoder interrupt
unsigned long t0, nextTick; long lastCount = 0;
void setup() {
  Serial.begin(115200);
  pinMode(MOTOR_PWM_PIN, OUTPUT);
  delay(2000);                        // motor at rest
  t0 = micros(); nextTick = t0 + LOG_US;
  analogWrite(MOTOR_PWM_PIN, (int)(PWM_STEP_PERCENT * 2.55f));   // the step happens at t = 0
}
void loop() {
  if ((long)(micros() - nextTick) < 0) return;
  nextTick += LOG_US;
  long c = encoderCount;
  float speed = (c - lastCount) / (LOG_US * 1e-6f);   // counts per second; convert to mm/s with your calibration
  lastCount = c;
  Serial.print((micros() - t0) * 1e-6f, 4); Serial.print(','); Serial.println(speed);
  if (micros() - t0 > 1500000UL) analogWrite(MOTOR_PWM_PIN, 0);  // stop after 1.5 s
}

    3. Controller design

    PI design for a first-order plant

    With \(u=K_pe+K_i\!\int e\,dt\) the closed loop is \(\tau s^2+(1+KK_p)s+KK_i=0\). Matching it to \(s^2+2\zeta\omega_ns+\omega_n^2\) gives

    \[ \omega_n=\frac{4}{\zeta\,t_s},\qquad K_p=\frac{2\zeta\tau\omega_n-1}{K},\qquad K_i=\frac{\tau\,\omega_n^2}{K} \]

    The settling time \(t_s\approx4/(\zeta\omega_n)\) is the usual 2% estimate. The PI zero adds a little overshoot beyond the second-order formula, so the simulation below is the judge.
