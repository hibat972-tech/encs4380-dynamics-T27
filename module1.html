Module 1 of 4: thermometer-type sensors

First-order time response

A first-order sensor has one energy store, such as the heat stored in a thermometer bulb. It cannot jump to a new value. It moves towards it exponentially, and one number, the time constant τ, sets how fast.

Theory in two minutes

Model

Input \(x(t)\) is the true quantity; output \(y(t)\) is what the sensor reports.

\[ \tau\,\dot y + y = K\,x \] \[ G(s)=\frac{Y(s)}{X(s)}=\frac{K}{\tau s+1} \]

\(K\) is the static sensitivity (output units per input unit). \(\tau\) is the time constant in seconds.

Step input \(x = A\)

\[ y(t)=KA\left(1-e^{-t/\tau}\right) \]

At \(t=\tau\): \(1-e^{-1}=0.632\), so 63.2% of the final value. At \(t=3\tau\): \(1-e^{-3}=0.950\), so 95%. The final value is \(KA\), so the steady-state error is zero.

Ramp input \(x = Rt\)

\[ y(t)=KR\left(t-\tau+\tau e^{-t/\tau}\right) \] \[ y(t)\;\to\;KR\,(t-\tau)\quad (t \gg \tau) \]

Once the transient dies out, the output is the ideal output delayed by exactly \(\tau\). The reading is always \(R\tau\) behind the true value: that is the steady-state error \(e_{ss}=R\tau\).

Log method for \(\tau\)

\[ E_m=\frac{y_\infty-y(t)}{y_\infty-y(0)}=e^{-t/\tau} \] \[ \ln E_m=-\frac{t}{\tau} \]

On a logarithmic axis the error fraction is a straight line. Its slope is \(-1/\tau\). Fitting that line uses every data point, not just one, so it is the robust way to find \(\tau\) from real (noisy) data.

Sensor and input

Thermometer example from the assignment: τ = 10 s, from room air at 20 °C into tea at 80 °C (x₀ = 20 °C, A = 60 °C, K = 1). The plot then shows the actual temperature reading.

Input and output

Measurement error \(e(t)=x(t)-y(t)/K\)

True input minus what the sensor indicates, in input units. Its final value is the steady-state error.

Error fraction on a log axis

What to notice

  • Change K: the curve stretches vertically but the 63.2% point stays at the same time. Timing depends only on τ.
  • Double τ: every time on the plot doubles, and the error-fraction line becomes half as steep.
  • Switch to a ramp: the output runs parallel to the ideal line, shifted right by τ. A faster ramp (bigger R) gives a bigger error, but the time lag stays τ.
  • The error-fraction plot stays a straight line whatever K, A or R are. That is why the log method works on any first-order data set.

Engineering meaning

  • A reading taken at \(t=\tau\) after a sudden change is still 36.8% short. Wait at least \(3\tau\) (95%) or \(5\tau\) (99.3%) before trusting it.
  • For a slowly changing quantity (a ramp), a first-order sensor never catches up. It always lags by τ seconds, which is an error of \(R\tau\) in input units.
  • Reducing τ (smaller bulb, thinner sheath, better thermal contact) cuts both the settling time and the ramp error.
